# Applied Machine Learning & Deep Learning

A portfolio of machine learning and deep learning models focusing on supervised estimation, unsupervised segmentation, and generative neural networks. 

### Tech Stack
Python, TensorFlow, Keras, scikit-learn, NumPy, Pandas.

### Architectures & Methodologies
*   **Supervised Learning:** Implemented multi-class classification and continuous regression models to predict hardware pricing and concrete compressive strength. Focused on feature engineering and mitigating multicollinearity.
*   **Unsupervised Learning:** Applied K-Means clustering for customer segmentation and association rule mining to map transactional dependencies in market basket datasets. 
*   **Deep Learning (CV & NLP):** Built Convolutional Autoencoders to isolate signal from Gaussian noise in images. Developed Dense Neural Networks (MLP) for binary sentiment analysis of variable-length text sequences.

### Engineering Highlights
*   **Hyperparameter Optimization:** Designed manual Grid Search pipelines to tune learning rates, batch sizes, and network depth, strictly balancing model capacity against early overfitting.
*   **Data Sanitization:** Enforced rigorous pre-processing, including Interquartile Range (IQR) outlier removal and `StandardScaler` normalization to maintain geometric integrity in distance-based clustering and gradient descent stability.
